## 架构

UI → 命令库/筛选/选择规则 → 原子文件保存。平台服务拥有托盘、全局热键、单实例和自启动。
检索与原子保存均为本项目自研；应用只依赖 GPUI 与组件库，不引入终端、PTY 等无关层。
文件写入在后台进行，结果回传 UI；成功提示以操作完成为准。

## 实现细节

- 独立 v2 命令库使用命令上的 groups 数组和内置模板 metadata，关联共享同一 ID。
- 旧版 organization.membership 单值迁移为数组；null 明确迁移为空分组。
- 多词命中为主路径，未匹配时叠加有界编辑距离以支持拼写近似。
- 后台线程串行处理文件操作，每次写入加锁后重新读取，原子替换；失败不覆盖旧文件。
- 选择使用有序 ID 列表，查看已选独立于当前过滤器，防止隐藏选择无法复核。
- 全局热键先注册新键；设置写入失败回滚，旧键仍有效。原生对象保持主线程所有权。
- 安装器只收录程序/文档/许可，不收录用户 data 文件；卸载不删除 data。

## 0.1.1 长列表滚动修复（2026-10-19，离屏验证通过）

### 问题与原因

长命令列表的外层使用普通 div，未形成传递剩余高度的纵向 flex 容器；内层按内容扩张后被窗口裁剪，缺少可靠的滚动视口。另一个独立问题是方向键使用 UniformListScrollHandle，但实际列表是普通 Div 且没有 track_scroll，因此方向键选到视口外也不会滚动。

### 已实现

- 使用有明确高度约束的纵向 flex 视口，min_h_0 和 overflow_hidden 逐层传递；实际列表 size_full + overflow_y_scroll。
- 改用实际绑定的 ScrollHandle；可变高度命令行禁止收缩，保证正文、备注摘要和标签不挤成一行。
- 右侧使用原组件库 Scrollbar，可滚轮、触控板及拖动滚动条；方向键滚动到当前选中行。
- 切换搜索/分组/标签/已选视图重置滚动位置，保留勾选顺序。
- 版本升至 0.1.1，设置与托盘提示显示版本；安装器和源码包名称由 Cargo 版本产生。
