# 版本记录

## 0.3.0 — 2026-11-02

代码与授权独立，常驻内存降低：

- 检索与原子写入两个模块按行为重新实现，不再保有外部代码；`nucleo-matcher` 依赖移除，打分改为内置五档（整字段 / 前缀 / 词首 / 内含 / 散落）加紧凑度微调。
- 许可由 GPL-3.0-or-later 改为 MIT；不再附带外部源码副本与来源清单。
- 窗口收进托盘时释放工作集：隐藏态由约 20 MB 降至 1–2 MB，可见态不受影响。
- 内置图标移除旧命名前缀。
- 编译并行度限制为 4，避免全量重编时 rustc 占满内存。
- README 改为简练表述，补资源占用实测与源码结构表。

## 0.2.0 — 2026-10-21

界面重做，交互补齐：

- 新增深色 / 浅色双主题，在「设置 → 外观」切换并立即预览，保存后随下次启动生效。
- 面板由 430 加宽到 520；命令行与分组行统一 60 高，行内改为「名称 + 标签胶囊」与命令正文两行，备注移入详情页与编辑页。
- 标签从 `#a #b` 拼接文本改为胶囊 chip，列表内最多显示两个，其余折叠为 `+N`。
- 多选序号改为圆形徽标；选中态、键盘光标态和已复制态改用左侧强调条与底色区分，修复悬停覆盖已选配色的问题。
- 搜索框显示命中条数；空状态区分「命令库为空」与「没有匹配结果」，并给出对应操作。
- 工具栏按钮尺寸统一；危险操作改用红色变体，确认页补充取消按钮与警示图标。
- 状态提示改为浮层 toast，不再挤压列表高度。
- 窗口高度按行内容精确计算，修正长列表被裁切的问题；各子页面按内容设置窗口尺寸。
- 窗口可拖动：在搜索区上下留白或工具栏空白处按住移动。拖到屏幕左/右边缘自动贴边收起只留 6px，鼠标靠近滑出，移开 0.7 秒收回。
- 新增 `COMMAND_MANAGER_INSTANCE` 环境变量，便于开发版与已安装版本并行运行。

数据格式不变；升级前从托盘退出旧程序，将新版安装到原目录。安装器保留 data 文件夹。

## 0.1.1 — 2026-10-19

- 修复命令或分组较多时列表被裁切、无法上下滚动的问题。
- 支持滚轮、触控板与拖动右侧滚动条；搜索和新增入口保持固定。
- 修复方向键选择列表外命令时不自动滚动的问题。
- 切换搜索、分组、标签或已选视图时重置滚动位置，保留批量选择顺序。
- 设置页面和托盘提示增加版本号，打包文件名同步版本。
- 新增 4 项 GPUI 离屏回归测试，使用 200 条混合高度记录验证双向滚动、滚动条拖动、末行可达及筛选偏移归零。

数据格式不变；升级前从托盘退出旧程序，将新版安装到原目录。安装器保留 data 文件夹。
