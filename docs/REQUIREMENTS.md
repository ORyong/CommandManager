# 确认的需求

状态：需求已确认，实现和验证状态见 DEVELOPMENT.md。

1. Rust + GPUI 原技术，独立 Windows 应用，沿用截图深色样式和控件。
2. 后台常驻托盘，默认 Ctrl+Alt+X 切换显示/隐藏；快捷键可改，冲突可见。托盘点击和再次启动仍呼出已有窗口。
3. 关闭、失焦收起，菜单和编辑期间不误收起；托盘菜单真正退出。单实例。
4. 自启动默认关闭，可设置开启。
5. 命令新增、编辑、删除；多行备注、多个标签；列表摘要和完整详情。
6. 平级多分组，按软件组织；一条命令可关联多个分组，修改同步。
7. 分组/标签增删改；删除分类只解除关联。
8. 搜索覆盖名称、正文、备注和标签，始终全局；大小写忽略、缩写、多词和近似匹配。
9. 标签筛选默认 AND，可切换 OR，与关键词搜索叠加。
10. 单条点击复制正文；反馈约 800 ms 后收起；失败不收起。
11. 多选点击只勾选，按勾选顺序编号、换行复制、按 ID 去重；取消重选排最后。
12. 跨搜索/分组/标签保留选择；查看已选、清空选择。
13. 备注和标签不复制；保留命令内部换行，批量不额外追加末尾换行。
14. 数据保存在安装目录/data；导入导出含元数据；兼容早期的单分组文件。
15. 内置模板正文保留；可编辑元数据，另存自定义副本后修改正文。
16. 当前用户可写安装目录，可选择路径；升级卸载保留数据。
17. 交付安装包、完整源码、样式和构建说明，无 Python/Rust 运行环境要求。
18. 每阶段同步 Markdown，严格区分计划、实现和实际验证。
19. 标签输入完成按回车直接保存：编辑命令时保存当前命令的全部字段；新建/重命名标签时提交当前标签。校验失败保留输入并显示原因；备注框回车仍用于换行。

20. 长命令列表和分组列表支持滚轮/触控板及拖动滚动条，搜索框、管理栏和新增入口固定；方向键选中超出视口的行时自动滚动。切换搜索、分组、标签和已选视图重置滚动位置，保留选择顺序。

## 默认值

界面中文、Nord 深色；弹窗可调整大小。无云同步、无自动执行命令。
初次手动启动显示窗口，自启动静默驻留。再次启动唤醒已有实例。
复制成功后清空本次批量选择；新的弹出清空关键词，避免上次搜索误限结果。
